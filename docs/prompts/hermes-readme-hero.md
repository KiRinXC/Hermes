# Hermes README Hero Image Prompt

Use this prompt to generate a polished bitmap hero image for the README.

## Prompt

Create a clean, premium product illustration for a Windows desktop AI translation app named "Hermes".

Scene: a friendly red octopus inspired by an app icon shaped like a curled octopus tentacle sits in the center of a bright, modern desktop workspace. Each tentacle gently attaches to or taps a floating application card around it, showing common apps where translation works: Chrome, Edge, VS Code, Notion, Slack, Microsoft Word, and a PDF reader. The visual metaphor should clearly communicate "one translation assistant reaches across many apps".

Style: modern SaaS product hero illustration, refined and trustworthy, soft 3D or high-end editorial illustration, smooth shapes, subtle shadows, clean composition, elegant details, not childish, not cartoonish. The octopus should be red with slight coral gradients, friendly eyes, and a subtle Hermes brand feel. Use a light neutral background with soft depth, enough whitespace for README readability.

Composition: wide horizontal image, centered octopus, app cards arranged in an arc around it, tentacles visibly connecting to each app card. Keep the center uncluttered and avoid covering the octopus face. Leave safe margins on all sides. The image should still read well at GitHub README width.

Text: no large text, no UI paragraphs, no fake screenshots, no illegible labels. App cards may use simple recognizable icons or short labels only if clean and readable.

Color palette: red/coral octopus, white and light gray surfaces, subtle blue accents, minimal dark text, premium Windows 11 inspired softness.

Output: 16:9 or 21:9 wide hero image, high resolution, crisp details, no watermark.

## Negative Prompt

Avoid horror, realistic sea creature anatomy, wet textures, chaotic tentacles, busy background, childish cartoon mascot, overly cute sticker style, dark cyberpunk lighting, excessive gradients, blurry app icons, unreadable text, fake brand logos that look distorted, watermark, signature, UI screenshots with tiny text.
