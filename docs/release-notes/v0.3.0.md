# Hermes v0.3.0

Hermes v0.3.0 introduces an extensible built-in application center, led by Codex authentication switching and local session alignment, alongside a more compact settings experience.

## Download

Download:

```text
Hermes-v0.3.0-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Added an extensible **Applications** center to Hermes settings.
- Added **Codex Authentication Manager** for switching between ChatGPT and API authentication profiles.
- Added official browser login through `codex login`, with discovery through PATH, npm installations, and supported editor extensions.
- Added complete `config.toml` and `auth.json` profile import for arbitrary, case-sensitive API providers.
- Added local Codex session Provider alignment across rollout files and the authoritative `state_5.sqlite` database.

## Codex Profile Safety

- ChatGPT and API profiles are encrypted with Windows DPAPI for the current Windows user.
- Authentication switches recursively merge the target config into the active config, preserving MCP servers, plugins, projects, features, and other undeclared local settings.
- `auth.json` is replaced as one credential unit, while obsolete authentication-routing keys are removed when switching modes.
- Switching, browser login, and active API edits use backups, atomic file replacement, SQLite transactions, read-back verification, and rollback on failure.
- API credentials are decrypted only for the active edit session and cleared from the editor after saving or leaving the page.

## Interface Improvements

- Replaced system confirmation dialogs in Codex flows with Hermes-native confirmation cards.
- Simplified authentication cards so each state shows only relevant actions and one primary action.
- Added rollout counts for all records, regular sessions, internal agents, and archived sessions.
- Moved privacy settings into **General**, reducing settings navigation from six tabs to five.
- Removed repetitive helper text while retaining dynamic status, errors, recovery guidance, and privacy boundaries.

## Maintenance and Security

- Removed the obsolete API setup path that embedded an early development endpoint and fixed model defaults.
- Updated `Microsoft.Data.Sqlite` to `10.0.11`, resolving the vulnerable SQLite native dependency reported in earlier builds.
- Isolated multi-project intermediate output and improved release-directory lock checks.

## Known Limitations

- Codex session alignment changes local Provider metadata only; it does not upload conversations to ChatGPT or provide cross-device cloud sync.
- Encrypted content created under another authentication owner may still be unavailable after switching.
- Exit Codex desktop apps, CLI processes, ChatGPT, and IDE Codex extensions before login, switching, or synchronization.
- Browser login requires either Codex CLI or a supported official Codex editor extension containing the Codex executable.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
