# Hermes v0.2.2

Hermes v0.2.2 is a focused hotfix for Ctrl/Alt mouse-selection triggering.

## Download

Download:

```text
Hermes-v0.2.2-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Hold `Ctrl` before selecting text to show the floating translation button.
- Hold `Alt` before selecting text to show the same floating button for explanation mode.
- Mouse and keyboard release order no longer matters after a valid Ctrl/Alt selection starts.
- Ctrl/Alt key presses and releases no longer close a newly displayed passive floating button.

## Fixes

- Fixed a regression where the floating button only appeared when Ctrl/Alt and the mouse button were released at nearly the same time.
- Fixed missed selection-start modifier detection by caching low-level keyboard hook state and message timestamps.
- Fixed late modifier presses being treated as valid triggers after a mouse selection had already started.

## Known Limitations

- Windows apps expose selected text in different ways. Some apps may still need hotkey translation or clipboard fallback instead of the passive floating button.
- Explanation mode requires an OpenAI or OpenAI-compatible API key.
- Tencent Transmart availability depends on network access to the configured endpoint.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
