# Hermes v0.2.0

Hermes v0.2.0 focuses on provider flexibility, term explanation, faster selection handling, and a more polished floating translation experience for everyday Windows use.

## Download

Download:

```text
Hermes-v0.2.0-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Tencent Transmart is now the default translation provider, so normal translation can work without an OpenAI API key.
- OpenAI and OpenAI-compatible endpoints remain available for translation, and are still used for explanation mode.
- Translation settings now use separate `AI translation` and `AI explanation` channels, with a toggle for sending translation through OpenAI.
- Hold `Ctrl` while selecting text to translate, or hold `Alt` while selecting text to explain a term or phrase.
- Explanation mode supports a configurable preference prompt, so users can tune how detailed or domain-specific explanations should be.
- Passive selection handling is faster and more compatible with apps such as PDF readers, Zotero, Electron apps, and custom text controls.
- Passive selection no longer blocks on slow UI Automation reads; clicking the floating button still performs the explicit selection read and controlled clipboard fallback.
- The floating button is less likely to appear twice after quick selections or delayed background checks.
- Translation cards support richer Markdown rendering, including headings, lists, quotes, code blocks, inline code, emphasis, and links.
- Multiple pinned translation cards are tracked independently, so retry and close actions stay attached to the correct card.
- Translation and settings windows can be resized from edges and corners, and translation card size is remembered.
- Appearance settings now include floating button style, floating button size, and translation popup font size controls.
- Loading states show the actual runtime channel, such as `Tencent`, an OpenAI model name, or the active explanation model.
- Light theme readability, button contrast, scrollbars, startup notification behavior, and settings layout have been refined.

## Fixes

- Fixed a routing regression where translation could still go through OpenAI after the OpenAI translation toggle was turned off.
- Fixed a candidate-flow cancellation issue that could leave floating-button translation stuck in loading.
- Fixed several Chinese UI text readability issues in the translation popup.
- Fixed Markdown streaming edge cases where unfinished markers could render incorrectly or stall updates.
- Fixed pinned-card event isolation so older cards no longer interfere with the current translation request.
- Reduced startup and passive-selection input lag by delaying global trigger registration and time-boxing selection checks.

## Known Limitations

- Windows apps expose selected text in different ways. Some apps may still need hotkey translation or clipboard fallback instead of the passive floating button.
- Explanation mode requires an OpenAI or OpenAI-compatible API key.
- Tencent Transmart availability depends on network access to the configured endpoint.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
