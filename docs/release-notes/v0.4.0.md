# Hermes 0.4.0

- 新增基于 GitHub Releases 的软件更新：后台自动检查并提醒；常规页右侧按钮可手动检查，最新版就地显示结果，发现新版时按钮切换为“更新”，点击后 Hermes 自动退出、完成更新并重新打开。
- Codex 认证切换和浏览器登录等待界面改用主题化环形状态动效与轻量悬浮卡片，移除原生横向进度条和整页黑色遮罩，并继续支持取消登录。
- ChatGPT 浏览器登录支持主动取消，退出 Hermes 时自动清理 `codex login` 进程树。
- 登录取消、失败或意外中断时恢复原 Codex 配置、认证与 ChatGPT 档案。
- Codex 进程提示显示来源与 PID，便于区分 IDE 扩展、CLI 和 Hermes 登录任务。
