# Hermes v0.2.3

Hermes v0.2.3 tightens passive Ctrl/Alt selection triggering after real-world testing.

## Download

Download:

```text
Hermes-v0.2.3-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Passive floating buttons now require Ctrl or Alt to already be held when the mouse selection starts.
- Normal mouse text selection no longer enters the passive floating-button flow.
- Mouse and keyboard release order remains flexible after a valid Ctrl/Alt selection starts.

## Fixes

- Fixed ordinary mouse selections incorrectly showing the floating translation button.
- Fixed late Ctrl/Alt presses being accepted after the mouse button was already down.
- Tightened the keyboard hook interval check so only an active modifier state at selection start is accepted.

## Known Limitations

- Windows apps expose selected text in different ways. Some apps may still need hotkey translation or clipboard fallback instead of the passive floating button.
- Explanation mode requires an OpenAI or OpenAI-compatible API key.
- Tencent Transmart availability depends on network access to the configured endpoint.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
