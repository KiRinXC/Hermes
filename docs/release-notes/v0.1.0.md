# Hermes v0.1.0

Hermes is a Windows global AI translation assistant. It helps you translate selected English text into Simplified Chinese without leaving the app you are working in.

## Download

Download:

```text
Hermes-v0.1.0-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Global hotkey translation, default `Ctrl+Alt+E`.
- Hold `Ctrl` while selecting text to show the floating translation button.
- Streaming AI translation through the OpenAI-compatible Responses API.
- Floating translation card with copy, retry, pin, close, and drag support.
- OpenAI-compatible Base URL and model configuration.
- API Key encrypted locally with Windows DPAPI.
- Light, dark, and system theme support.
- Translation history is off by default.

## Known Limitations

- Windows apps expose text selection differently. Some apps may need hotkey or clipboard fallback instead of the floating button.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
