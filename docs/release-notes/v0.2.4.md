# Hermes v0.2.4

Hermes v0.2.4 improves selection reliability and prevents stale clipboard text from entering translation requests.

## Download

Download:

```text
Hermes-v0.2.4-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Floating-button translation now stays bound to the window where the selection was created.
- Controlled clipboard fallback only accepts text produced by the current `Ctrl+C` operation.
- Passive Ctrl/Alt selection now verifies both the physical key state and the low-level hook timeline.

## Fixes

- Fixed floating-button clicks sometimes failing to read the selected text in slower applications.
- Fixed previously copied clipboard text being translated when the current selection copy failed.
- Fixed ordinary selections showing the floating button because of stale modifier-key hook state.
- Increased the controlled-copy wait budget from 90ms to 350ms while keeping clipboard work off the UI thread.
- Restored the original clipboard after every controlled-copy attempt, including failure paths.

## Developer Experience

- Build and release scripts can discover the workspace .NET SDK from `HERMES_DOTNET_ROOT`, the configured C:/D: workspace locations, or `PATH`.
- Added regression coverage for fresh clipboard updates, source-window binding, and physical modifier-key gating.

## Known Limitations

- Windows apps expose selected text in different ways. Some apps may still need hotkey translation or the tray clipboard command.
- Explanation mode requires an OpenAI or OpenAI-compatible API key.
- Tencent Transmart availability depends on network access to the configured endpoint.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
