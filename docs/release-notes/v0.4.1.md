# Hermes 0.4.1

本次更新集中修复 Hermes 运行时可能影响正常 `Ctrl+C` / `Ctrl+V` 的问题，并进一步收紧划词阶段的隐私与资源边界。

## 修复内容

- 被动划词阶段不再通过 UI Automation 预读或缓存选区正文。
- 被动划词阶段不读取剪贴板，也不会模拟 `Ctrl+C`；只有按翻译快捷键、点击悬浮按钮或选择“翻译剪贴板”后才会真正取词。
- 低级键盘和鼠标 Hook 只记录输入状态并转发事件，关闭悬浮 UI 等 WPF 工作改为异步排队和合并，降低对正常复制粘贴输入链路的干扰。
- 悬浮按钮候选只保存手势、前台窗口和鼠标位置，不再持有未明确触发翻译的选区正文。

## 行为说明

- 按住 `Ctrl` 或 `Alt` 划词后，悬浮按钮会直接显示在鼠标释放位置附近；点击按钮后才读取并校验选区。
- 因为按钮显示前不再读取正文，无有效文本时按钮也可能出现；点击后 Hermes 会显示明确提示，不会发送空内容。
- UI Automation 无法读取选区时，受控剪贴板兜底仍会在用户明确触发后执行，并在完成后恢复原剪贴板。

## 安装与更新

- 新用户下载 `Hermes-win-Setup.exe` 安装即可，无需额外安装 .NET Runtime。
- 已安装 v0.4.0 的用户可在“设置 → 常规 → 软件更新”中检查更新并升级到 v0.4.1。
- 当前版本尚未进行代码签名，Windows SmartScreen 可能显示未知发布者提示。
