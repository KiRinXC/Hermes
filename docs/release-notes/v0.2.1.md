# Hermes v0.2.1

Hermes v0.2.1 is a small stability update for high-DPI Windows setups and default provider behavior.

## Download

Download:

```text
Hermes-v0.2.1-win-x64-portable.zip
```

Unzip it and run:

```text
Hermes.Windows.exe
```

This is a `win-x64 self-contained` portable build. You do not need to install .NET Runtime separately.

## Highlights

- Improved placement of WPF floating UI on high-DPI displays, including 200% scaled laptop panels.
- Floating translation buttons, translation cards, tray notifications, and tray menus now use DPI-aware physical screen positioning.
- Overlay hit-testing now compares mouse points against physical window bounds, reducing accidental outside-click handling on scaled displays.
- Translation defaults are reinforced so packaged builds use Tencent Transmart without requiring an API key.
- Legacy OpenAI provider settings are preserved for users who want them later, but no longer automatically enable OpenAI translation during compatibility migration.

## Fixes

- Fixed offset or off-screen placement after switching from an external display to the built-in laptop screen.
- Fixed tray notification and tray menu placement on high-DPI screens.
- Fixed floating button direction and containment checks when display scaling is greater than 100%.
- Fixed stale legacy OpenAI settings causing translation to route through OpenAI by default.

## Known Limitations

- Explanation mode still requires an OpenAI or OpenAI-compatible API key.
- Tencent Transmart availability depends on network access to the configured endpoint.
- The app is not code signed yet, so Windows SmartScreen may show an unknown publisher warning.
- Current release is a portable package, not a full installer.
